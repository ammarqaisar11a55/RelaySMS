# RelaySMS

Private companion SMS app: a source Android phone that holds the SIM forwards a copy of its
incoming SMS, end-to-end encrypted, to a paired companion Android phone over the internet. The
companion shows them in RelaySMS's own inbox.

Work in progress. See [docs/IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md) and
[docs/FEASIBILITY.md](docs/FEASIBILITY.md).
